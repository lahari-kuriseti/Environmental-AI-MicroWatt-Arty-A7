# Wildfire Detection and Classification

## Project Overview

This module focuses on developing a dataset-based AI system for wildfire detection and risk classification using Python and FPGA implementation.

## Objectives

- Collect historical wildfire datasets.
- Preprocess temperature, humidity, wind speed and rainfall data.
- Train a machine learning model using Python.
- Evaluate model performance.
- Implement the trained model using VHDL.
- Integrate the wildfire AI module with MicroWatt on the Arty A7-100T FPGA.

## Input Features

- Temperature
- Relative humidity
- Wind speed
- Rainfall
- Vegetation dryness

## Expected Output

Wildfire risk classification:
- Low
- Moderate
- High
- Critical

## Tools and Technologies

- Python
- Machine Learning
- VHDL
- GHDL
- MicroWatt
- Arty A7-100T FPGA
