# MicroWatt Integration

## Overview
This folder will contain the integration of the Environmental AI system with the MicroWatt processor on the Arty A7-100T FPGA.

## Objectives
- Develop a Wishbone-compatible AI peripheral.
- Connect the AI inference modules to MicroWatt.
- Implement memory-mapped registers.
- Enable processor-based control and result retrieval.
- Test communication through UART.

## Tools
- MicroWatt
- VHDL
- Wishbone Bus
- GHDL
- Arty A7-100T FPGA
