# Flood Detection and Classification

## Project Overview
This module focuses on developing a dataset-based AI system for flood detection and risk classification using Python and FPGA implementation.

## Objectives
- Collect historical flood-related datasets.
- Preprocess rainfall, river water-level and soil moisture data.
- Train a machine learning classification model using Python.
- Evaluate the model's performance.
- Implement the trained model using VHDL.
- Integrate the flood AI module with MicroWatt on the Arty A7-100T FPGA.

## Input Features
- Rainfall
- River water level
- Soil moisture
- Previous rainfall measurements

## Expected Output
Flood risk classification:
- Low
- Moderate
- High
- Critical

## Tools and Technologies
- Python
- Machine Learning
- VHDL
- GHDL
- MicroWatt
- Arty A7-100T FPGA
